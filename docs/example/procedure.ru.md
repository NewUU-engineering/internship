Пройдите эту страницу перед каждым занятием.

!!! danger "Перед каждым занятием"

    Подтвердите комбинацию аварийной остановки со всеми присутствующими и
    обеспечьте 2 м свободного пола вокруг оборудования.

## Как остановить устройство

Физической кнопки аварийной остановки в этой конфигурации нет. Остановка —
это действие с пульта, и правильное действие зависит от ситуации.

| Ситуация | Действие | Результат |
| --- | --- | --- |
| Движется не туда, ситуация под контролем | 1× ++start++ | Возвращается в стойку и удерживает её |
| Выполняется последовательность, нужно прервать | 2× ++start++ | Последовательность прерывается |
| **Аварийная ситуация: риск для людей** {: .row-danger } | ++l2+b++{: .kbd-danger } | Режим демпфирования — устройство **медленно опускается на пол** |
| Пульт не отвечает | Кнопка батареи | **Только после подвешивания**, ноги над полом, 2 м свободного пространства |

!!! warning "Двойное нажатие — не аварийная остановка"

    Двойное нажатие прерывает текущее действие. Если ничего не выполняется,
    устройство шагает на месте — а оператор считает, что нажал стоп.

## Процедура перед занятием

<div class="steps" markdown>

1.  **Освободите рабочее место.** Не менее 2 м свободного пола вокруг
    устройства. Только сухая, твёрдая, ровная поверхность.

2.  **Подтвердите комбинацию остановки с каждым участником.** Каждый
    присутствующий произносит комбинацию вслух: ++l2+b++{: .kbd-danger }

3.  **Проверьте батарею.** Ниже 20 % устройство может сесть без предупреждения.

4.  **Запишите занятие.** Дата, оператор, серийный номер устройства.

</div>
